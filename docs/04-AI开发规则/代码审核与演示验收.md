# 代码审核与演示验收

## 已安装审核相关 Skills

- `security-best-practices`：JS/TS 安全最佳实践审查。
- `security-threat-model`：登录、钱包、提现、后台权限、游戏公平性的威胁建模。
- `security-ownership-map`：有 git 历史后分析敏感代码归属和 bus factor。
- `sentry`：后续接入运行期错误追踪。
- `gh-fix-ci`：后续接入 GitHub 后修复 CI 失败。
- `playwright` / `playwright-interactive`：H5 演示前做浏览器自动化验收。

## 本地审核命令

当前 monorepo 已保留本地审核入口：

```bash
cd /Users/newcoin/Desktop/棋牌室
npm run audit:local
```

这个命令会执行：

- 斗地主规则和状态机单元测试。
- 不依赖 `.env` 或 Telegram Token 的本地验证入口。

也可以单独执行：

```bash
npm test
```

## 演示前必须通过

- `npm run audit:local` 全绿。
- Bot 启动不报错。
- `/start`、打开 H5、查询积分、最近战绩、分享邀请、客服入口可走通。
- 斗地主 H5 或本地演示中的叫分、出牌、提示、结算可走通。
- 不读取、不展示 `.env` 中的 Bot Token。

## 重要限制

审核命令只能证明已覆盖场景通过，不能证明代码绝对没有 bug。后续要提高可信度，需要继续补：

- H5 Playwright 演示脚本。
- 真实三人 WebSocket 房间测试。
- 钱包账本幂等和对账测试。
- Telegram initData 校验测试。
- Sentry 运行期错误上报。
