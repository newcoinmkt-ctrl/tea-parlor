## 当前代码状态

旧 `tg/` 原型能力已经吸收到 monorepo：

- `apps/bot/` 保留 Telegram 入口、打开 H5、查询积分、最近战绩、分享邀请和客服入口。
- `packages/doudizhu-engine/` 保留 JJ 经典斗地主牌型识别、叫分、出牌、AI 辅助、结算和无 Token 自动演示。
- H5 大厅和游戏服务在 `apps/web-lobby/`、`apps/colyseus-tea-parlor/`、`apps/pinus-tea-parlor/`、`apps/game-servers/` 中继续演进。

当前不足：

- 仍需持续补强真实多人房的稳定性、断线重连、托管和 Playwright 端到端覆盖。
- 德州扑克、麻将等非斗地主玩法仍以占位或阶段性实现为主。
- 真实充值、提现、真钱、USDT 结算不属于当前阶段能力。

## Skills 状态

已安装并适合本项目使用：

- `playwright`：H5 自动化、UI 回归、移动端截图。
- `playwright-interactive`：交互式调试 H5 游戏流程。
- `screenshot`：桌面截图验收。
- `security-best-practices`：JS/TS 安全审查。
- `security-threat-model`：登录、钱包、提现、游戏公平性威胁建模。
- `security-ownership-map`：安全责任边界梳理。
- `pdf`：读取和核对 PDF/文档渲染。
- `vercel-deploy`、`netlify-deploy`、`cloudflare-deploy`：后续部署。
- `notion-knowledge-capture`、`notion-research-documentation`、`notion-spec-to-implementation`：需求整理和规格落地。
- `sentry`：后续接入运行期错误追踪。
- `gh-fix-ci`：接入 GitHub 后用于定位和修复 CI 失败。
- GitHub 插件：用于后续搜索/读取 GitHub 仓库、PR、Issues。

官方 Skills 列表中暂未发现专门的 Telegram Bot、Web3 钱包或棋牌规则技能，因此这些能力需要在项目内用工程文档和代码规范约束。
