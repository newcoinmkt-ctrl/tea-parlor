# 炸金花 · 规则与玩法说明

> 对齐 `packages/zhajinhua-engine` 与 `apps/web-lobby/src/games/zhajinhua/`。  
> 元宝场与真金入口（试玩金）规则相同。

---

## 1. 简介

| 项目 | 说明 |
|------|------|
| 人数 | **3 人** |
| 牌 | 标准扑克，每人 **3 张** 暗牌 |
| 目标 | 通过下注与比牌，以牌型最大者（或最后存活者）赢池 |

---

## 2. 牌型（强 → 弱）

| 类型 | 说明 |
|------|------|
| 豹子 | 三点相同，AAA > KKK > … > 222 |
| 顺金 | 同花顺；QKA 最大，A23 最小 |
| 金花 | 同花非顺，比高牌再比次牌 |
| 顺子 | 连续非同花，A23 最小 |
| 对子 | 对子点 + 单张踢脚 |
| 散牌 | 高牌 |

### 特殊：235（豹子杀手）

- **1v1 比牌**：场上**有豹子**时，2·3·5 **仅克豹子**；对其他牌型 235 仍按最小散牌处理。
- **场上无豹子**：2·3·5 为**最小散牌**。
- **多人亮牌**：同时有 235 与豹子时，避免非传递循环：豹子垫底、235 仅高于豹子，其余按常规强度。

---

## 3. 流程与操作

```
WAITING → DEALING → BETTING → SETTLING
```

| 操作 | 规则 |
|------|------|
| 闷牌 | 未看牌状态下跟注/加注，单注为闷牌底注 |
| 看牌 | 看后单注变为闷牌单注的 **×2** |
| 跟注 / 加注 | 不超过场上限；看牌玩家按看牌单注 |
| 比牌 | 消耗 = 发起方当前单注 **×2**，输者出局 |
| All-in | 投入剩余筹码；不足单注时进入边池逻辑 |
| 弃牌 | 退出本局，不再参与池 |

仅剩 **1 人存活** → 立即结算，赢家收 pot。  
`pot === sum(betTotal)` 全程守恒。

---

## 4. All-in 与边池

- 按 `betTotal` 分层主池 / 边池。
- All-in 玩家仅参与其投入覆盖的池层。
- 各池独立比牌发奖；奇数筹码等细节以实现为准。

开牌触发示例：全员 All-in；仅 1 人仍有可操作筹码且他人 All-in；轮数达上限。

---

## 5. AI 与公平

- AI 性格：激进 / 稳健 / 均衡；综合胜率、轮数、池热度、加注史。
- 可选公平洗牌校验码（演示）；服务端可叠加反作弊采样。

## 6. 真金入口

- 场次示例：真金微注（ante/stake 用试玩金）。
- 入座最低试玩金见大厅房间卡；规则与元宝场一致。
