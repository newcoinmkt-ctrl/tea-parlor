# JJ 斗地主 · 规则与玩法说明

> 依据 JJ 官方帮助中心、官网介绍及公开百科资料整理，覆盖**经典三人叫分斗地主**主干规则。  
> 不同房间 / 锦标赛细则（炸弹倍率、封顶、加倍）以进房显示的**实际规则**为准。  
> 资料来源：JJ 帮助中心「斗地主规则」、jj.cn 斗地主介绍、公开百科条目等。  
> 大厅全玩法总览与真金入口说明见 [平台玩法说明.md](./平台玩法说明.md)。元宝场与真金入口规则一致。

---

## 1. 游戏简介

| 项目 | 说明 |
|------|------|
| 平台 | JJ 斗地主（竞技世界），PC / 手机 / TV 等 |
| 经典人数 | **3 人一桌** |
| 牌副 | **1 副扑克，共 54 张**（含大小王） |
| 阵营 | **地主 1 人** vs **农民 2 人**（农民为一方） |
| 胜负 | 任一方有人**先出完手牌**则该方获胜（地主先完则地主赢；任一农民先完则农民赢） |

JJ 另提供多种变体：**经典斗、欢乐斗、癞子（赖斗）、闪电斗、二人斗、四人斗、连炸** 等，以及锦标赛 / 排位等赛制。下文默认写**经典三人叫分玩法**。

---

## 2. 一局流程总览

```
准备入座（3 人）
    ↓
发牌（每人 17 张，留 3 张底牌，定地主前不可看底牌）
    ↓
叫分（1 / 2 / 3 分或不叫）
    ↓
确定地主 → 亮底牌给地主并公开显示
    ↓
地主先出牌 → 逆时针跟牌 / 不出
    ↓
有人出完 → 结算积分
```

---

## 3. 发牌

1. 使用 **1 副 54 张** 标准扑克。  
2. 每名玩家发 **17 张**，余下 **3 张为底牌**。  
3. **在确定地主之前，任何玩家都不能看底牌**。  
4. 确定地主后：  
   - 3 张底牌交给**地主**（地主手牌变为 20 张）；  
   - **底牌对所有人可见**（亮底）。

---

## 4. 叫分（抢地主）

### 4.1 基本规则

- 叫分起点：常见为**随机一人**开始（官网亦有「拿到一张明牌的玩家先叫分」的描述，以具体客户端为准）。  
- 顺序：**逆时针**。  
- 可选操作：**叫 1 分 / 2 分 / 3 分**，或**不叫（放弃）**。  
- **后叫者只能叫比前面已叫分更高的分**，或选择不叫。  
- 若有人叫 **3 分**：叫分**立即结束**，该玩家成为地主。  
- 一轮结束无人叫到 3 分：由**叫分最高者**当地主。  
- **若一轮中所有人都不叫**：  
  - 按 JJ 帮助中心说明：由**开始叫分的人**当地主，底分为 **1 分**；  
  - 部分公开介绍写「都不叫则重新发牌」——**以当前房间实际规则为准**。  
- **超时**：约 **20 秒**不叫分，视为**不叫**，并可能进入托管。

### 4.2 叫分与底分

叫分结果成为本局**底分（叫分分值）**，进入结算公式（见第 8 节）。

---

## 5. 出牌

### 5.1 顺序与跟牌

- **地主获得首出权**。  
- 之后按 **逆时针** 顺序行动。  
- 轮到跟牌时：  
  - 出**比上家更大的同类型牌**；或  
  - 选择 **「不出」**（让过）。  
- 若连续两家「不出」，则**上一轮出牌者再次获得自由出牌权**（可出任意合法牌型）。  
- 任意玩家**手牌出完**，本局结束。

### 5.2 超时与托管

| 情况 | 处理（经典帮助中心描述） |
|------|--------------------------|
| 约 **15 秒**未操作 | 可能自动「不出」、或由系统打出最小单张等（以房间为准） |
| 点击「托管」/ 超时托管 | 系统代打；托管时默认倾向不出，获自由出牌权时可能自动打最小单张 |
| 可「取消托管」 | 玩家重新手动操作 |
| 剩余 **1 张** 仍托管 | 系统自动出完 |

## 6. 牌点大小

### 6.1 单牌点数（从大到小）

```
大王 > 小王 > 2 > A > K > Q > J > 10 > 9 > 8 > 7 > 6 > 5 > 4 > 3
```

- **花色不比大小**（同点数视为同大，用于对子 / 三张等点数比较）。  
- **大王 + 小王** 组成 **火箭（王炸）**，为最大牌型。

### 6.2 牌型一览

| 牌型 | 说明 | 示例 |
|------|------|------|
| **单张** | 任意 1 张 | 3、K、小王 |
| **对子** | 点数相同的 2 张 | 88、AA |
| **三张** | 点数相同的 3 张 | 777 |
| **三带一** | 三张 + 1 张单牌 | 333+6 |
| **三带二** | 三张 + 1 个对子 | 444+99 |
| **顺子** | ≥5 张连续单牌；**不能含 2 与王** | 3-4-5-6-7；7-8-9-10-J-Q-K |
| **连对（双顺）** | ≥3 个连续对子；**不能含 2 与王** | 33-44-55；77-88-99-1010 |
| **飞机（三顺）** | ≥2 组连续三张；**不能含 2 与王** | 333-444；555-666-777 |
| **飞机带翅膀** | 飞机 + 同数量单牌或同数量对子 | 444-555+7-9；333-444-555+77-99-JJ |
| **四带二** | 四张 + 2 张单牌 **或** 2 个对子（**四带二不算炸弹**） | 5555+3+8；4444+55+77 |
| **炸弹** | 点数相同的 4 张 | 7777 |
| **火箭** | 大王 + 小王 | 王炸 |

> 说明：部分房间对「飞机带牌」「四带二」细节可能微调，以客户端提示为准。

### 6.3 比大小规则

1. **火箭** > **炸弹** > **一切普通牌型**。  
2. **炸弹之间**：比点数大小（如 8888 > 5555）。  
3. **普通牌型**之间：  
   - 必须 **牌型相同** 才能压制（单压单、对压对、同长度顺子压顺子等）；  
   - 比较 **主体点数**（如三带一比三张的点数，不比带的那张）。  
4. **不同长度 / 不同类型** 的普通牌一般**不能互压**（炸弹 / 火箭除外）。

## 7. 春天（常见附加）

公开资料与通用斗地主习惯中：

| 名称 | 含义 | 效果（常见） |
|------|------|----------------|
| **春天** | 地主出完，两名农民**都没有出过牌** | 倍数再 ×2 |
| **反春** | 某一农民先出完，**地主只出过一手牌**（首出后未再出） | 倍数再 ×2 |

是否启用、是否计入封顶，以 JJ **具体房间 / 赛事规则**为准。

## 8. 计分规则（JJ 帮助中心）

### 8.1 基本公式

一局结束后：

```
地主得分 = 2 × 胜负参数 × 基数 × 底分 × 倍数
农民得分 =     胜负参数 × 基数 × 底分 × 倍数
```

| 符号 | 含义 |
|------|------|
| **胜负参数** | 该方胜 = **+1**；该方负 = **-1** |
| **基数** | 房间设定的记分基数（不同场次不同） |
| **底分** | 叫分阶段得到的 1 / 2 / 3 分 |
| **倍数** | 由炸弹、火箭、春天等按房间规则累计 |

含义简述：

- **地主赢**：地主得正分（约为两农民绝对值之和）；两农民各得负分。  
- **地主输**：地主得负分；两农民各得正分。  
- 地主一人对两人，故公式中地主一侧系数为 **2**。

### 8.2 锦标赛炸弹计分示例（官方帮助）

规则示例（**以比赛实际规则为准**）：

- 叫 **1 分**时：每个炸弹倍数 **+1 或 +1.5**（看赛事）；  
- 叫 **2 分或 3 分**时：每个炸弹倍数 **+2**。

**示例**（地主叫 3 分，基数 100）：

| 局面 | 计算 | 地主得分 |
|------|------|----------|
| 赢 1 炸 | (3+2)×100×2 | **1000** |
| 赢 2 炸 | (3+2+2)×100×2 | **1400** |
| 赢 3 炸 | (3+2+2+2)×100×2 | **1800** |

岛屿赛等其它赛制炸弹规则另有说明，进房查看。

### 8.3 「输赢以小」原则（JJ 特色）

为维护公平、避免破产碾压，JJ 计分常使用 **「输赢以小」**：

1. 玩家赢分 **不会超过自己携带的积分**。  
2. 玩家输分 **不超过自己携带的积分**；若不够赔付两家农民，则按规则在农民之间 **按比例分配** 能赔付的部分。  
3. 地主胜时，两农民分别输给地主的数额，与地主负时分别赔给两农民的算法对称。

**举例（帮助中心思路）**：  
地主带 1000 分，两农民应各赢 600 与 900，但农民 A 只带 300、农民 B 只带 750 → 按携带上限与比例重新分配，且地主最多输掉自己的 1000 分。

### 8.4 托管 / 逃跑相关（比赛常见）

- 逃跑或长期托管：可能按 **全输** 或系统规则结算（以赛事说明为准）。  
- 托管超过一定局数：可能 **扣分 / 加罚**，且仍为托管状态时输赢另有加减分。

### 8.5 平分 / 晋级（赛事）

- 同局或积分相同时，可能按 **「得分高者优先 / 先到达者优先」** 等规则排名。  
- 预选赛积分可能按比例折算为 **JJ 积分** 进入下一阶段。

## 9. JJ 上的主要玩法变体（产品向）

| 玩法 | 特点（概括） |
|------|----------------|
| **经典斗地主** | 三人、叫分、标准牌型，本文主干 |
| **欢乐斗 / 叫地主** | 多为「叫地主 / 抢地主」流程，与纯 1–3 分叫分不同 |
| **癞子斗（赖斗）** | 随机癞子可当任意牌，炸弹与倍数规则更复杂 |
| **闪电斗** | 节奏更快的限时 / 简化对局 |
| **二人斗地主** | 2 人，牌量与规则调整 |
| **四人斗地主** | 4 人，多使用两副牌等扩展规则 |
| **连炸等** | 强调连续炸弹等特殊倍数 |

此外平台还有 **麻将、象棋、掼蛋、升级、跑得快** 等，不属于斗地主本体。

## 11. 策略速记（非官方，便于上手）

1. **叫分**：看炸弹、火箭、长顺、控牌 2 与 A 再决定 1/2/3。  
2. **农民配合**：优先接应队友、尽量不拆关键连牌；对家要走时让路。  
3. **地主**：利用底牌信息控节奏，适时用炸弹清场。  
4. **记牌**：跟踪 2、王、炸弹与大顺是否已出。

## 12. 与实现相关的规则要点（研发摘要）

若要对标 JJ 经典场做引擎，建议优先实现：

1. 54 张牌库、17+17+17+3 发牌；  
2. 叫分状态机（1/2/3/不叫、必高于前者、3 分截断、流局策略可配置）；  
3. 底牌归属 + 全员可见；  
4. 出牌合法性：牌型识别、同型比大、炸弹/火箭压制；  
5. 轮转：首出 / 跟牌 / 双过回手；  
6. 结算：底分 × 倍数 × 基数 × 阵营系数 2；  
7. 可选：春天、输赢以小、托管超时、炸弹倍率表配置化。
