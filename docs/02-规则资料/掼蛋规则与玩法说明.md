# 掼蛋 · 规则与玩法说明

> 对齐 `packages/guandan-engine` 已实现逻辑（牌型识别、逢人配、压制比较等）及产品规划中的进贡 / 接风 / 升级。  
> 大厅「玩法说明 → 掼蛋」分栏与本文一致；完整 H5 桌面流程持续接入中。

---

## 1. 简介

| 项目 | 说明 |
|------|------|
| 人数 | **4 人**，两两成队（对家为队友） |
| 牌副 | **两副**扑克，共 **108** 张 |
| 目标 | 按**级牌**多局升级；先打过 **A** 并满足过 A 条件的一方通关获胜 |

### 点数序（比点用）

**大王 > 小王 > 级牌（当前等级） > A > K > … > 3 > 2**

- 级牌点数**仅次于大小王**，**高于 A**。  
- 当前打级为 `currentRank` 时，**红心 + 该点数**为 **逢人配**（可替代除大小王外任意点数）。

---

## 2. 牌型

| 类型 | 说明 |
|------|------|
| 单张 / 对子 / 三张 | 基础 |
| 三带二 | 三张 + 一对 |
| 木板（三连对） | ≥3 连续对子 |
| 钢板 | ≥2 连续三张 |
| 顺子 | 五张连续（非同花） |
| 同花顺 | 五张同花连续（特殊炸弹位） |
| 炸弹 | 4 张及以上同点 |
| 天王炸 | 四王 |

### 逢人配组牌

- 手中 1～2 张逢人配时，穷举合法替代，取合法解释。  
- 优先组**同花顺 / 高张数炸弹**，其次钢板 / 木板，尽量避免拆成单张。

---

## 3. 压制比较 `canSuppress`

### 3.1 普通牌型

- 须**同类型且张数/节数相同**。  
- 比较首张（主点数）的 `rankStrength`（含级牌抬升）。

### 3.2 炸弹压制链（大 → 小）

```
天王炸（四王）
  > 8 张及以上炸弹
  > 7 张炸弹
  > 6 张炸弹
  > 同花顺
  > 5 张炸弹
  > 4 张炸弹
  > 普通非炸弹牌型
```

### 3.3 特殊

- **相同张数**：同花顺 **>** 同张数普通炸弹（如 5 张同花顺 > 5 张普通炸）。  
- **同花顺 vs 同花顺**：比最大单张点数（级牌序）。  
- 炸弹可压任意普通牌型；更大炸弹层压更小层。

引擎：`canSuppress(handA, handB, currentRank)`、`compareGuanDanHands`、`bombTier`、`rankStrength`。

## 4. 进贡与退贡（开局前）

状态流：

```
WaitingTribute → CheckingAntiTribute → ExecutingTribute → ReturningTribute → GameStart
```

### 4.1 进贡类型（依上一局名次：头游 / 二游 / 三游 / 末游）

| 类型 | 条件 | 行为 |
|------|------|------|
| 双进贡 | 对家组合得三游、末游（双下） | 末游、三游分别向头游、二游进最大牌 |
| 单进贡 | 一家末游 | 末游向头游进最大牌 |

### 4.2 抗贡

- **双进贡**：两名进贡方手牌**合计 2 张大王** → 抗贡，取消进贡直接开局。  
- **单进贡**：进贡方手牌有 **2 张大王** → 抗贡。

### 4.3 进贡 / 还贡

- 进贡：自动打出除**红心级牌（逢人配）**外手中最大的牌。  
- 还贡（退贡）：收贡方选择一张 **点数 ≤ 10** 的牌还给进贡方。

---

## 5. 接风（Pass Wind）

当某玩家清空手牌（成为头游 / 二游等）后：

- 若**无人压**其最后一手牌，则下一出牌权交给其**同组队友**（接风）。

---

## 6. 升级与过 A

### 6.1 `calculateLevelProgress(ranks)`

| 队友名次 | 升级 |
|----------|------|
| 1、2 名（双下） | 胜方 **升 3 级**（打 A 时满足条件则**通关**） |
| 1、3 名 | 胜方 **升 2 级** |
| 1、4 名 | 胜方 **升 1 级** |

### 6.2 打 A / 过 A 限制

- 当前级为 **A** 时：必须取得 **双下（1+2）** 或 **1+3** 才算真正过 A。  
- 若仅取得 **1+4**：本局**不升级**，下一局**继续打 A**。

支持多局累计比分与通关胜负校验（`GuanDanSettlement` 规划模块）。

## 7. AI 要点（2v2）

| 策略 | 说明 |
|------|------|
| 队友保护 | 上家是队友且牌少 → 尽量过牌或出小牌喂牌 |
| 压制残局 | 敌方剩 1～2 张 → 优先多张牌型压单张 |
| 逢人配 | 优先同花顺 / 大炸 / 钢板木板，少拆单 |
| 防通牌 | 服务端记录异常顶牌/喂牌、同 IP 等风控告警 |
