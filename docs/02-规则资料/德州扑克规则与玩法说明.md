# 德州扑克 · 规则与玩法说明

> 对齐 `packages/texas-engine` 与 `apps/web-lobby/src/texas/`。  
> 桌面默认 **3 人无限注（No-Limit）**。元宝场与真金入口规则相同。

---

## 1. 简介

| 项目 | 说明 |
|------|------|
| 人数 | 大厅默认 **3 人**（引擎支持多座位） |
| 底牌 / 公共牌 | 每人 **2** 张底牌 + 桌面 **5** 张公共牌 |
| 比牌 | **7 选 5** 组成最佳 5 张 |
| 注型 | **无限注（NL）**：可全下 |

---

## 2. 一局流程

```
发盲注（SB / BB）
  → 翻前（每人 2 底牌）下注
  → 翻牌 3 张
  → 转牌 1 张
  → 河牌 1 张
  → 摊牌 / 边池分配
```

可选 Straddle（引擎配置）。

### 操作

| 动作 | 说明 |
|------|------|
| Fold | 弃牌 |
| Call / Check | 跟注 / 过牌 |
| Raise | 加注到指定总额 |
| All-in | 投入全部筹码 |

---

## 3. 牌型（强 → 弱）

| 类别 | 名称 |
|------|------|
| 9 | 皇家同花顺 |
| 8 | 同花顺 |
| 7 | 四条 |
| 6 | 葫芦 |
| 5 | 同花 |
| 4 | 顺子 |
| 3 | 三条 |
| 2 | 两对 |
| 1 | 一对 |
| 0 | 高牌 |

同类别再比踢脚（如 `A-A-K-J-8` > `A-A-K-10-9`）。

---

## 4. 边池

- 按本手总投入 `betTotal` 分层主池 / 边池。
- All-in 玩家仅有资格赢取自己投入覆盖的池。
- 平局分池；奇数筹码按靠近 SB 等规则分配（见引擎 `distributePots`）。

---

## 5. 公平与风控（引擎能力）

| 模块 | 说明 |
|------|------|
| 公平洗牌 | HMAC-SHA256 等可验证哈希（演示） |
| Hand History | 可导出 PokerStars 风格牌谱 |
| 合谋检测 | 异常顶牌/喂牌等行为采样告警（服务端侧） |

---

## 6. 场次（大厅）

| 类型 | 示例 |
|------|------|
| 元宝 | 微盲 / 常规等，影子筹码带入 |
| 真金 | 微盲 0.5/1（带入 10 试玩金）、常规 1/2（带入 25）等 |

结算：局末弹窗；真金场筹码折回试玩金账本（演示）。
