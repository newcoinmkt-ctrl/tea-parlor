# 茶馆大厅 · 平台玩法说明

> 与 `apps/web-lobby` 当前可玩内容对齐。侧栏「玩法说明」弹层分栏文案以此文档为准。  
> 元宝场与**真金入口**（内部试玩金账本）**规则一致**，仅结算币种不同。试玩金/元宝均**不可兑现**、非链上资产。

## 1. 入口与货币

| 项目 | 说明 |
|------|------|
| 侧栏 | 大厅 · 斗地主 · 德州 · 炸金花 · 麻将 · 真金入口 · 更多游戏 · 战绩 · 玩法说明 |
| 元宝 | 影子积分，本地/人机试玩 |
| 试玩金 | 真金入口内部账本；可在补给中心领取或演示预存 |
| 每日补给 | 仅当元宝为 0 时可领，每天最多 4 次 |
| 真金入口 | 斗地主 / 德州 / 炸金花 / 麻将试玩金桌 + 玩法快捷跳转 |
