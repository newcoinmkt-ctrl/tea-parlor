# 四川麻将 · 规则与玩法说明

> 对齐 `packages/mahjong-engine` 与 `apps/web-lobby/src/games/mahjong/`。  
> 牌组为四川标准 **108 张**（万、条、筒，**无字牌**）。元宝 / 真金入口规则相同。

---

## 1. 模式一览

| 模式 | 人数 | 流程要点 | 胡后 |
|------|------|----------|------|
| 二人麻将 | 2 | 首胡结算；无换三张 / 无定缺 | 首胡结束 |
| 四人经典 | 4 | 首胡结算；无换三张 / 无定缺 | 首胡结束 |
| 血战到底 | 4 | 换三张 → 定缺 → 对局 | 胡牌**退场**，最多 3 家胡 |
| 血流成河 | 4 | 换三张 → 定缺 → 对局 | 胡后**留场**可再胡；杠/胡可实时分 |

---

## 2. 换三张与定缺（血战 / 血流）

1. **换三张**：各家交出 **同花色 3 张**，按方向（顺时针 / 逆时针 / 对家）交换。  
2. **定缺**：选定一门花色为本局缺门；手中不得再保留定缺花色才能胡牌。  
3. 引擎可推荐：换牌优先定缺色；定缺优先张数最少花色。

---

## 3. 操作

| 操作 | 说明 |
|------|------|
| 摸 / 打 | 点选打出 |
| 碰 | 三张明刻 |
| 杠 | 明杠（直杠）、补杠、暗杠 |
| 胡 | 满足定缺 + 胡型 |

### 杠分（刮风下雨，示意）

- 按底分 `baseScore` 即时结算（直杠由点炮方付；暗杠/补杠由其余在场玩家分摊等，以实现为准）。
- 血流模式下杠/胡可多次累计。

---

## 4. 结算差异

| 模式 | 结算 |
|------|------|
| 二人 / 四人经典 | 首胡后汇总本局分 |
| 血战 | 胡牌者退场，继续至最多三家胡或荒牌 |
| 血流 | 胡后留场，可继续胡；终局汇总实时分 |

`checkMahjongSettlements` 汇总杠分 + 胡分报告。
