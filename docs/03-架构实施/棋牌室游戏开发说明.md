# 棋牌室游戏开发说明

## 1. 产品定义

Tea Parlor 是 Telegram Bot + H5 Mini App 棋牌室。第一阶段不是做赌场系统，而是做可运营的棋牌游戏厅：

- Bot：入口、拉新、通知、分享、查询、客服。
- H5：大厅、玩法、场次、牌桌、资产、任务和战绩。
- 后端：登录、匹配、房间、游戏状态机、钱包账本、运营配置、风控审计。

首发游戏：

| 游戏 | MVP 范围 | 规则来源 |
|------|----------|----------|
| 斗地主 | 经典三人叫分斗地主 | JJ 斗地主经典公开规则 |
| 德州扑克 | 朋友房/积分桌，先不做真金桌 | 标准 Texas Hold'em |
| 麻将 | 先做一种基础规则，地区规则插件化 | 需后续确认地区玩法 |

## 2. 推荐架构

```
Telegram Bot
  -> 打开 H5 Mini App
  -> 发送匹配、结算、活动通知

H5 Mini App
  -> API Gateway 校验 Telegram initData
  -> Lobby Service 获取玩法和场次
  -> Game Server WebSocket 进入牌桌
  -> Wallet Service 展示余额和流水

Game Servers
  -> doudizhu
  -> texas-holdem
  -> mahjong
  -> future-games
```

## 4. 游戏插件接口

每个游戏必须提供统一接口：

| 接口 | 说明 |
|------|------|
| `createRoom(config)` | 创建房间 |
| `joinRoom(roomId, player)` | 玩家入座 |
| `startRound(roomId)` | 开局 |
| `applyAction(roomId, playerId, action)` | 处理叫分、出牌、下注、摸打等动作 |
| `getPublicState(roomId, viewerId)` | 返回视角化牌桌状态 |
| `settleRound(roomId)` | 生成结算意图 |
| `replay(roomId)` | 回放牌谱和关键事件 |

游戏服务只产出结算意图，不能直接改余额。

## 5. 斗地主 MVP 规则

以 `docs/02-规则资料/JJ斗地主规则与玩法说明.md` 为准，优先实现：

- 54 张牌、每人 17 张、3 张底牌。
- 1/2/3 分或不叫，后叫必须高于前者。
- 叫 3 分立即结束叫分。
- 无人叫分时首家当地主、底分 1，作为默认配置。
- 地主获得底牌并首出。
- 单、对、三、三带一、三带对、顺子、连对、飞机、飞机带翅、四带二、炸弹、火箭。
- 火箭最大，炸弹压普通牌，同牌型同长度比主体点数。
- 炸弹/火箭倍数翻倍。
- 春天/反春可配置。
- 结算采用地主 2 倍、农民 1 倍，并预留“输赢以小”封顶。

## 6. 德州扑克 MVP 规则

第一阶段只做积分好友房或测试场：

- 2-9 人桌。
- 小盲、大盲、翻牌、转牌、河牌、摊牌。
- 行动：弃牌、过牌、跟注、加注、全下。
- 边池和手牌比较必须用成熟规则库或完整测试覆盖。
- 不接真实资金桌。

## 7. 麻将 MVP 规则

麻将地区规则差异很大，第一阶段必须先确认玩法。未确认前只保留：

- `mahjong` 插件入口。
- 房间配置模型。
- UI 占位。
- 规则接口。

不要默认把某个地方麻将规则写成平台标准。

## 8. 资产与数字货币

阶段划分：

| 阶段 | 能力 | 说明 |
|------|------|------|
| Phase 1A | 影子积分 | 内部账本、无链上充值提现 |
| Phase 1B | 测试链/沙盒充值 | 仅测试环境，验证对账 |
| Phase 2 | 有限制数字货币接入 | 必须完成合规、KYC/AML、地区限制、风控 |
| Phase 3 | 真实提现 | 必须人工审核、冷热钱包、限额、异常冻结 |

账本要求：

- 所有余额变化必须有 `ledger_entry`。
- 游戏开始先锁定带入分，结束后结算释放。
- 每次结算必须有幂等键。
- 所有充值、提现、游戏输赢必须可对账、可回放。

## 9. UI 方向

参照 QQ 斗地主棋牌室，但不能直接复制商标、素材和受保护资产。可借鉴：

- 绿色牌桌。
- 木质/金色边框。
- 顶部资产栏。
- 大厅分区：经典场、好友房、赛事、任务、商城。
- 三人座位布局。
- 清晰的叫地主/叫分/出牌/不出/提示按钮。
- 移动端优先，桌面端自适应。

## 10. 验收标准

MVP 必须做到：

- TG Bot 能拉起 H5 Mini App。
- Telegram initData 登录校验通过。
- 大厅展示斗地主、德州扑克、麻将三个入口，德州和麻将可先为未开放状态。
- 斗地主至少 2 个场次。
- 3 人可以进入同一房间并完整打一局。
- 叫分、出牌、结算和余额流水一致。
- 断线重连能恢复牌桌。
- 超时托管能让对局继续。
- 规则引擎有自动化测试。
- H5 移动端截图无严重遮挡和溢出。
