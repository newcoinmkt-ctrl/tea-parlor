# 多人框架整合说明（Pinus + Colyseus）

## 结论：H5 优先 Colyseus，Pinus 兼容保留

| 维度 | Colyseus | Pinus |
|------|----------|-------|
| 源码 | `external/colyseus` | `external/pinus` |
| 业务服 | `apps/colyseus-tea-parlor` | `apps/pinus-tea-parlor` |
| 端口 | **2567** | **3010** |
| 协议 | Colyseus Room 消息 | Pomelo/Pinus hybrid |
| H5 客户端 | `public/colyseus/colyseus.js` + `src/net/colyseus-client.js` | `public/pinus/pinusclient.js` + `src/pinus/client.js` |
| 规则 | `@tea-parlor/doudizhu-engine` | 同左 |
| 推荐场景 | **H5 房间、匹配、权威对局** | 多进程 connector、既有接入 |

统一模式键：`tea-parlor-play-mode` = `local` | `colyseus` | `pinus`  
模块：`apps/web-lobby/src/net/play-mode.js`

## 架构

```text
┌──────────── web-lobby H5 ────────────┐
│  playMode: local | colyseus | pinus  │
│  本地：jj/* 人机                     │
│  联网：applyPinusRoom(同构快照)      │
└───────────┬────────────┬─────────────┘
            │            │
     Colyseus Room    Pinus connector
     :2567 doudizhu   :3010 ddzHandler
            │            │
            └─────┬──────┘
                  ▼
         packages/doudizhu-engine
         （唯一规则权威实现）
```

## 合规与资产

- 联网桌仍只结算影子元宝 / 试玩金，经 H5 本地账本演示。
- 真钱、链上结算不走游戏服；须 Wallet/Ledger + 合规。

## 启动验收

1. `npm run colyseus:start` → `/health` 返回 ok  
2. H5 切 **Colyseus 联网** → 进斗地主 → 叫分/出牌  
3. 失败自动回退本地人机
