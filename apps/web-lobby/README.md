# Web Lobby App

H5 Mini App lobby MVP for game entries, room selection, shadow-points display, and table navigation.

Current scope:

- First screen is the operational lobby, not a marketing page.
- Shows user profile and internal shadow points.
- Shows Doudizhu, Texas Hold'em, and Mahjong entries.
- Doudizhu has multiple room entries.
- Texas Hold'em and Mahjong are marked as not open.
- No QQ/JJ brand assets are used.
